## Limits

This is mock-tested local software. Browser JavaScript rendering/visual/accessibility, live cPanel UAPI, PostgreSQL/Redis restart recovery, WebAuthn/passkeys, verified-contact notification delivery, authenticator rebinding, external production secret management/key rotation, distributed throttling, and production deployment were not verified. The smoke test serves the HTML entry and exercises API traffic through Vite, but it does not claim browser-rendered UI verification. Tenant isolation was tested with two synthetic organizations in the local fixture database. The browser failure is environment access evidence, not a software pass. SQLite uses Node's experimental built-in SQLite API in the available runtime. Evidence does not establish provider compatibility or production readiness.
